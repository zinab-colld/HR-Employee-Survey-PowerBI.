# 📊 HR Employee Survey Analysis & Interactive Dashboard

An end-to-end Data Analytics project transforming **14,700+ raw employee survey responses** into actionable organizational insights using **Power Query**, **DAX**, and **Power BI**.

## 🎯 Project Objectives
The goal of this project is to clean, model, and visualize HR survey dataset to evaluate employee satisfaction, completion rates, and sentiment trends across different roles and departments.

Key Metrics Analyzed:
- **Overall Completion Rate:** Track completed vs. incomplete survey submissions.
- **Departmental Performance:** Measure response volumes and satisfaction across 21 departments.
- **Role Distribution:** Breakdown of survey participants across Directors, Managers, Supervisors, Staff, and Unknown roles.
- **Sentiment & Ratings:** Analyze average response ratings across 12 specific workplace questions.

---

## Tools & Technologies
- **Power Query:** Data cleaning, custom conditional columns, deduplication, and string standardization.
- **DAX (Data Analysis Expressions):** Custom measures for KPIs (`Total Responses`, `Complete Responses`, `Completion Rate`, `Average Response Rating`).
- **Power BI Desktop:** Dashboard design, interactive slicers, conditional formatting, and visualization layout.

---

## Key Insights
- **Completion Rate:** Achieved an overall survey completion rate of **99.08%** across all departments.
- **Response Volume:** Over **14,500+ completed responses** recorded.
- **Top Participating Roles:** High participation among Supervisors and Staff categories.
- **Highest Rated Questions:** Clear expectations at work and direct supervisor support received the highest satisfaction scores across departments.
